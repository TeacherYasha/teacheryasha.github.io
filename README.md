# Teacher Yasha — reconstrução do site

Este projeto recria a página pública Teacher Yasha para hospedagem independente do Lovable, com base no HTML e CSS disponibilizados.

## Organização

- `index.html`: conteúdo da página e metadados
- `styles.css`: estilos visuais e animações
- `assets/`: imagens locais (a serem incluídas com autorização)

## Pré-visualização

Abra `index.html` no navegador ou use um servidor estático local.

## GitHub Pages

Em **Settings > Pages**, configure **Deploy from a branch**, selecione a branch `reconstrucao-lovable` e a pasta `/ (root)` para testar. Depois da aprovação, as alterações poderão ser incorporadas à `main`.

## Pendências antes da publicação definitiva

1. Baixar e adicionar as imagens com permissão de uso, substituindo os URLs da instância Lovable para garantir independência.
2. Substituir os links genéricos de WhatsApp (sem número) e Instagram pelo contato oficial.
3. Validar a fidelidade visual e os efeitos em desktop e celular.
4. Configurar domínio próprio no GitHub Pages.
